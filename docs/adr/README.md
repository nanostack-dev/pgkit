# Architectural decisions

There are no numbered ADRs in this repository yet. Existing runtime contracts remain in the [package documentation](../README.md#current-system); this index does not invent historical rationale.

For a new consequential choice, create `NNNN-<decision>.md` with status, context, decision, alternatives and consequences. Start at `0001`; preserve numbers and add a superseding record when a decision is reversed. Use technical documentation for current behavior and the issue or PR for temporary investigation notes.
